# Geometric Library

Небольшая библиотека на **Python** для вычисления площади и периметра геометрических фигур.

## Поддерживаемые фигуры

- круг;
- квадрат;
- прямоугольник.

## Файлы проекта

- `circle.py` — функции для работы с кругом;
- `square.py` — функции для работы с квадратом;
- `rectangle.py` — функции для работы с прямоугольником;
- `docs/README.md` — подробная документация проекта.

## Документация

Подробная документация находится в файле [docs/README.md](docs/README.md).

## Пример использования

```python
from circle import area

print(area(5))
```
