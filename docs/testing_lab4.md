# План тестирования geometric_lib

## 1. Цели и задачи тестирования
Проверить правильность расчёта площадей и периметров, выявить ошибки в формулах и обеспечить возможность повторной автоматической проверки после изменений кода.

## 2. Описание тестируемого продукта
geometric_lib — библиотека Python для расчёта площади и периметра круга, квадрата и прямоугольника. Функции принимают числовые размеры и возвращают результат вычисления.

## 3. Область тестирования
| Модуль | Функции | Число тестов |
| --- | --- | ---: |
| circle.py | area(r), perimeter(r) | 6 |
| square.py | area(a), perimeter(a) | 6 |
| rectangle.py | area(a, b), perimeter(a, b) | 8 |

Отрицательные размеры, неверные типы, производительность и безопасность не входят в область проверки: требования к ним в задании не определены.

## 4. Стратегия тестирования
Модульное функциональное тестирование с помощью unittest. Для каждой функции проверяются обычные и дробные значения; для площади и применимых периметров — нулевые размеры. Дополнительно проверяются квадрат как частный случай прямоугольника. Ожидаемые значения вычисляются заранее по математическим формулам. Для целых результатов применяется assertEqual, для вещественных — assertAlmostEqual.

Запуск из корня проекта: `python -m unittest -v test_geometry`.

## 5. Критерии приемки
Все 20 тестов обнаруживаются и выполняются без ошибок и отказов; охвачены все шесть функций; итоговый статус — OK.

## 6. Ожидаемые результаты
Протокол запуска содержит названия тестов, статусы и итоговое число проверок. При несовпадении ожидаемого и фактического результата unittest сообщает о дефекте. Выполнено 20 тестов, все успешно.
