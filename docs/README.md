# Документация проекта

## Общее описание решения

Проект представляет собой  библиотеку на **Python** для работы с геометрическими фигурами.

В проекте реализованы функции для вычисления площади и периметра следующих фигур:

- круга;
- квадрата;
- прямоугольника.

Исходный код расположен в файлах `circle.py`, `square.py` и `rectangle.py`.

## Описание функций

### `circle.area(r)`

Принимает радиус круга `r` и возвращает площадь круга.

**Пример вызова:**

```python
from circle import area

print(area(5))
```
### `circle.perimeter(r)`

Принимает радиус круга `r` и возвращает длину окружности.

**Пример вызова:**

```python
from circle import perimeter

print(perimeter(5))
```
### `square.area(a)`

Принимает сторону квадрата `a` и возвращает площадь квадрата.

**Пример вызова:**

```python
from square import area

print(area(123))
```
### `square.perimeter(a)`

Принимает сторону квадрата `a` и возвращает периметр квадрата.

**Пример вызова:**

```python
from square import perimeter

print(perimeter(5))
```
